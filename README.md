# ⏱️ WorkTime Tracker

Удобный, интерактивный и полностью автономный веб-табель для персонального учёта рабочего времени, контроля нормы трудозатрат и переработок.

Разработано без внешних тяжелых зависимостей (чистый Vanilla HTML5 / CSS3 / ES6+), работает прямо в браузере и сохраняет все данные локально (`localStorage`).

---

## 🚀 Основные возможности

- **Автоматический расчёт рабочего времени:**
  - Ввод времени начала и окончания рабочего дня.
  - Корректный учёт обеденного перерыва (по умолчанию 1.0 ч, настраивается).
  - Поддержка ночных смен и переходов через полночь (например, 22:00 → 02:00).
- **Гибкая классификация типов дней:**
  - `Р` — Рабочий день (норма 8.0 ч, настраивается)
  - `ПР` — Предпраздничный сокращённый (норма 7.0 ч)
  - `В` — Выходной день (норма 0.0 ч)
  - `П` — Праздничный день (норма 0.0 ч)
  - `О` — Отпуск (норма 0.0 ч)
  - `Б` — Больничный (норма 0.0 ч)
- **Контроль нормы и баланса (Дельта):**
  - Расчёт плановой нормы часов на месяц с учётом праздников, отпусков и больничных.
  - Мониторинг фактических трудозатрат.
  - Цветовая индикация переработки (`+ ч`) и недоработки (`- ч`).
  - Прогресс-бар выполнения месячного плана.
- **Универсальный календарь:**
  - Переключение между месяцами и годами.
  - Корректное отображение месяцев разной длины (28, 29, 30 и 31 день).
  - Автоматическое определение выходных (Сб/Вс).
- **Сохранение и экспорт данных:**
  - 100% приватность — данные не передаются на сервер, а хранятся в `localStorage` браузера.
  - **Экспорт в CSV** с поддержкой кодировки UTF-8 BOM для прямого открытия в Excel.
  - **Резервное копирование (JSON)** и восстановление данных на любом компьютере.
  - **Оптимизированная печать (Print View)** — аккуратный табель для отчёта руководству или бухгалтерии (`Ctrl+P`).
- **Быстрые действия:**
  - Кнопка *«Заполнить рабочие дни по умолчанию»* — заполняет пустые рабочие дни типовым графиком (например, 09:00 - 18:00) в один клик.

## 🛠️ Запуск проекта

Так как проект не требует сборщиков (Webpack/Vite) или серверной части:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Hermes-Bugaev-RV/work-time-tracker.git
   cd work-time-tracker
   ```
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Safari, Edge):
   - Двойным кликом по файлу `index.html`, либо
   - Через локальный сервер (например, VS Code Live Server или `python3 -m http.server 8080`).

## 🌐 Развёртывание на GitHub Pages

Проект идеально подходит для публикации на GitHub Pages:
1. Зайдите в репозиторий на GitHub: `Settings` → `Pages`.
2. В секции **Build and deployment** выберите источник `Deploy from a branch`.
3. Укажите ветку `main` и директорию `/ (root)`.
4. Нажмите **Save** — через минуту страница будет доступна по адресу `https://Hermes-Bugaev-RV.github.io/work-time-tracker/`.
